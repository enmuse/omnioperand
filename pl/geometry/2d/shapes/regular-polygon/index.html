Mathematical Foundations & Universal Proofs

A regular polygon is an equiangular and equilateral planar polygon. It belongs to the dihedral symmetry group Dn with n reflection axes and n-fold rotational symmetry (360° / n invariance). The following analytical proofs form the computational bedrock of the solver matrix.

1 Interior, Exterior, and Central Angles

▼

Any simple n-gon can be partitioned into (n - 2) non-overlapping triangles by drawing all non-intersecting diagonals from a single vertex. Because the interior angles of each triangle sum to 180°:

∑ (Interior Angles) = (n - 2) · 180° = (n - 2)π rad

Because all n interior angles are congruent:

α = [(n - 2) · 180°] / n = (1 - 2/n) · 180°

The exterior angle θ is supplementary to the interior angle:

θ = 180° - α = 180° - (180° - 360°/n) = 360° / n

The central angle β subtended by one side at the circumcenter equals the full circle divided by n:

β = 360° / n = (2π / n) rad = θ

2 Right-Triangle Decomposition: Inradius (ri) and Circumradius (R)

▼

Connecting the center of the polygon to any two adjacent vertices forms an isosceles triangle with vertex angle β = 2π / n and base length a. Dropping a perpendicular altitude from the center to the midpoint of the base bisects the triangle into two congruent right triangles:

  • Opposite leg = a / 2
  • Adjacent leg = Apothem / Inradius ri
  • Hypotenuse = Circumradius R
  • Angle at the center = β / 2 = π / n (or 180° / n)

Applying elementary trigonometry:

tan(π / n) = (a / 2) / ri ⟹ ri = a / [2 tan(π / n)]
sin(π / n) = (a / 2) / R ⟹ R = a / [2 sin(π / n)]

Furthermore, dividing the two equations gives the fundamental invariance:

ri / R = cos(π / n) ⟹ ri = R · cos(π / n)

3 Area from Triangulation, Apothem, and Circumradius

▼

A regular n-gon is the union of n congruent isosceles triangles, each having base a and height ri.

A = n · (½ · a · ri) = ½ (n · a) · ri = ½ P · ri

Substituting ri = a / [2 tan(π / n)]:

A = (n · a²) / [4 tan(π / n)]

Expressing the area strictly in terms of circumradius R using Area = ½ a b · sin(θ) for each triangle:

A = n · [½ R² · sin(2π / n)] = ½ n R² · sin(2π / n)

4 Total Diagonals Combinatorics & Diagonal Chord Lengths

▼

A diagonal is any line segment connecting two non-adjacent vertices. From any of the n vertices, we can draw line segments to all other vertices except itself and its two immediate neighbors, yielding (n - 3) diagonals per vertex. Multiplying by n and dividing by 2 (since segment ViVj = VjVi):

Nd = n(n - 3) / 2

Diagonals fall into ⌊n/2⌋ - 1 distinct length congruence classes. The k-th diagonal dk (skipping k edges along the perimeter) subtends an arc of k · (2π / n) on the circumscribed circle. Using the chord theorem:

dk = 2R · sin(kπ / n) = a · [sin(kπ / n) / sin(π / n)]

5 The Archimedean Limit as n ➔ ∞ (Method of Exhaustion)

▼

Around 250 BCE, Archimedes of Syracuse calculated the bounds of π by doubling polygon sides from hexagon (n = 6) to 12, 24, 48, and 96-gon. Taking the limit of perimeter and area as n ➔ ∞ with fixed circumradius R:

lim (n ➔ ∞) P = lim (n ➔ ∞) [2n R · sin(π/n)] = 2πR · lim (n ➔ ∞) [sin(π/n) / (π/n)] = 2πR
lim (n ➔ ∞) A = lim (n ➔ ∞) [½ n R² · sin(2π/n)] = πR² · lim (n ➔ ∞) [sin(2π/n) / (2π/n)] = πR²

Similarly, lim (n ➔ ∞) ri = lim (n ➔ ∞) [R · cos(π/n)] = R, proving that the polygon converges to a circle of radius R.

Często Zadawane Pytania

What is the formula for the area of any regular n-sided polygon? +
The area of any regular polygon with n sides of length a is A = (n · a²) / [4 tan(π/n)]. If you know the apothem (inradius) ri, the area is A = n · ri² · tan(π/n) = ½ P · ri. If you know the circumradius R, the area is A = ½ n R² · sin(2π/n).
How many diagonals does an n-gon have? +
An n-sided polygon has Nd = n(n - 3) / 2 diagonals. For example:
  • Triangle (n = 3): 3(0)/2 = 0 diagonals
  • Square (n = 4): 4(1)/2 = 2 diagonals
  • Pentagon (n = 5): 5(2)/2 = 5 diagonals
  • Hexagon (n = 6): 6(3)/2 = 9 diagonals
  • Octagon (n = 8): 8(5)/2 = 20 diagonals
  • Decagon (n = 10): 10(7)/2 = 35 diagonals
What is the difference between an apothem and a circumradius? +
The apothem (inradius ri) is the perpendicular distance from the center to the midpoint of any flat edge. It is the radius of the inscribed circle. The circumradius (R) is the distance from the center to any vertex corner. It is the radius of the circumscribed circle passing through all vertices. The two are always related by ri = R · cos(π / n).
Which regular polygons can be constructed with compass and straightedge? +
By the Gauss-Wantzel Theorem, a regular n-gon is constructible with compass and straightedge if and only if n is the product of a power of 2 and any number of distinct Fermat primes (3, 5, 17, 257, 65537). Constructible polygons include n = 3, 4, 5, 6, 8, 10, 12, 15, 16, 17, 20, 24, 30. Non-constructible regular polygons include n = 7, 9, 11, 13, 14, 18, 19.

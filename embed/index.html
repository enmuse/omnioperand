Embeddable Calculator Engine

Deploy high-precision interactive calculators directly onto your web property with a single line of script. Zero dependencies, isolated Shadow DOM styling, and customizable white-label branding.

⚡ 1-Minute Quick Start

Place the embed script in your document head or footer, then add a <div data-calculator="..."></div> anywhere on your page: 

<!-- 1. Include OmniOperand Embed Engine -->
<script src="https://omnioperand.com/embed/embed.js" async></script>

<!-- 2. Place Calculator Container -->
<div data-calculator="mortgage" data-theme="auto"></div>

Widget Configuration Attributes

Attribute Type Default Description
data-calculator string "mortgage" Calculator identifier: mortgage, octagon, compound-interest, cagr, concrete-volume
data-partner-id string "direct" Your partner or affiliate ID for tracking and white-label access
data-theme string "auto" Visual theme mode: "dark", "light", or "auto"
data-lead-capture boolean "false" When "true", renders an email gate before unlocking complete results
data-primary-color hex / css "#0284c7" Pro tier custom primary brand color

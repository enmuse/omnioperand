Frequently Asked Questions

Why is EVM storage (SSTORE) so expensive compared to memory (MSTORE)? +
SSTORE permanently writes 32 bytes of data to the global Ethereum state trie across tens of thousands of validator nodes worldwide, whereas memory (MSTORE) is temporary and wiped clean the instant the transaction finishes execution.
What is variable packing in Solidity? +
Solidity stores data in 32-byte slots. Packing multiple smaller types (e.g. uint128 + uint128, or uint64 + address) into a single 32-byte slot allows you to write multiple variables in a single 20,000-gas SSTORE instead of two separate writes.

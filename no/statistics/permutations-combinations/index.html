Analytisk Bevis og Invarianter

Maskinpresisjon
Styrende Matematisk Formel:
nPr = n! / (n - r)! | nCr = n! / [r! · (n - r)!]

Trinnvis Matematisk Utledning

1
Fundamental Counting Principle

Selecting r elements in order from n items yields n choices for the first, (n - 1) for the second, ..., down to (n - r + 1): nPr = n! / (n - r)!.

2
Symmetry and Division of Redundancy

If order is irrelevant, each group of r items can be arranged in r! identical ways: nCr = nPr / r! = n! / [r! · (n - r)!].

3
Pascal's Recurrence Identity

Binomial coefficients satisfy Pascal's rule: nCr = (n-1)C(r-1) + (n-1)Cr, mapping directly to rows of Pascal's Triangle.

Frequently Asked Questions

What is the key difference between permutations and combinations? +
Order matters in permutations (e.g., a locker combination lock is actually a permutation, where 1-2-3 is distinct from 3-2-1). Order does NOT matter in combinations (e.g., lottery numbers or poker hands).
Why is 0! equal to 1? +
By definition, there is exactly one way to arrange zero objects (the empty set). Defining 0! = 1 also preserves algebraic consistency in formulas like nPn = n! / 0! = n!.

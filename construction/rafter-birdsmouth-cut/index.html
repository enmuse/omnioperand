Verified Mathematical Identity

Run = (Span - Ridge) / 2 | L_line = Run · √[ 1 + (Pitch/12)² ] | HeelCut = Seat · (Pitch/12) ≤ Depth / 3

Analytical Derivation & Methodology

1
1. Theoretical Horizontal Run

For a symmetrical gable roof, horizontal run is half the building span minus half the ridge board thickness: Run = (Span - Ridge / 12) / 2.

2
2. Pitch Hypotenuse Factor & True Line Length

Roof pitch angle is θ = arctan(Pitch / 12). The line length factor is sec(θ) = √[1 + (Pitch / 12)²]. The true rafter line length from ridge work point to wall plate work point is L_line = Run × sec(θ).

3
3. Birdsmouth Seat & Heel Cut IRC Limits

The horizontal seat cut rests on the wall plate (minimum 1.5 inches per IRC R802.4.1). For full plate bearing, Seat = WallThickness. The vertical plumb heel cut depth is H = Seat × (Pitch / 12). IRC R802.4.1 strictly prohibits notching rafters deeper than one-third of the lumber depth (H ≤ Depth / 3) to prevent shear split.

Frequently Asked Questions

According to International Residential Code (IRC R802.4.1), the maximum vertical depth of a birdsmouth heel cut cannot exceed one-third (1/3) of the rafter depth. For a 2x8 (7.25" actual), the maximum heel cut is 2.41 inches.

Set your saw angle to the plumb angle θ = arctan(Pitch/12). For example, a 4/12 pitch is 18.4°, a 6/12 pitch is 26.6°, an 8/12 pitch is 33.7°, and a 12/12 pitch is 45.0°.

Total rafter board length equals the line length (from ridge cut to birdsmouth plumb line) PLUS the overhang tail length (from birdsmouth to fascia tail plumb cut) plus an allowance for square cuts.

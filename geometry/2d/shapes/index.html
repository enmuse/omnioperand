General Regular n-gon Mathematical Axioms

For any regular polygon with n sides of length a:

  • Interior Angle (α): α = (n - 2) × 180° / n = π(1 - 2/n) rad
  • Apothem / Inradius (ri): ri = a / [2 · tan(π / n)]
  • Circumradius (R): R = a / [2 · sin(π / n)]
  • Total Area (A): A = (n · a²) / [4 · tan(π / n)] = ½ · n · R² · sin(2π / n)
  • Total Diagonals (Nd): Nd = n(n - 3) / 2

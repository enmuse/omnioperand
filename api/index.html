Programmatic Integration Examples

Connect OmniOperand to any application, terminal, or autonomous AI framework in a single line of code.

1. cURL Terminal Command

curl -s "https://omnioperand.com/api/v1/geometry/2d/shapes/regular-polygon?n=8&driver=side&value=10" | jq

2. Python (Requests)

import requests

response = requests.get(
    "https://omnioperand.com/api/v1/geometry/2d/shapes/regular-polygon",
    params={"n": 8, "driver": "area", "value": 482.8427, "precision": 6}
)
data = response.json()
print("Side Length:", data["result"]["side"])
print("Circumradius:", data["result"]["circumradius"])
print("Invariance Verified:", data["result"]["verification"]["is_valid"])

3. JavaScript / TypeScript (fetch)

const params = new URLSearchParams({ n: '8', driver: 'side', value: '10' });
const res = await fetch(`https://omnioperand.com/api/v1/geometry/2d/shapes/regular-polygon?${params}`);
const data = await res.json();
console.log(`Area: ${data.result.area}, Apothem: ${data.result.apothem}`);

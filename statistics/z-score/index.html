Governing Mathematical Formula:
z = (x - μ) / σ | Φ(z) = ½ · [1 + erf(z / √2)]

Step-by-Step Mathematical Derivation

1
Standardization Normalization

The z-score measures how many standard deviations a raw observation x lies above or below the mean: z = (x - μ) / σ.

2
Gaussian Cumulative Distribution Function

Cumulative probability Φ(z) = (1 / √2π) ∫₋∞ᶻ e^(-t²/2) dt = ½[1 + erf(z / √2)], where erf is the Gauss error function.

3
Hypothesis Testing Benchmark

In two-tailed hypothesis testing, |z| ≥ 1.96 corresponds to p ≤ 0.05 (statistical significance), and |z| ≥ 2.576 corresponds to p ≤ 0.01.

Frequently Asked Questions

What does a negative z-score indicate? +
A negative z-score indicates that the data point is below the distribution mean. For example, z = -1.5 means the value is 1.5 standard deviations below average.
What percentage of data falls above z = 2.0? +
Because Φ(2.0) = 0.9772 (97.72% below), exactly 2.28% of observations in a normal distribution fall above z = +2.0.
